## Estado

Todo lo que aparece como «pendiente de validación» o «experimental» en la matriz de funciones **no está probado**. No se afirma que una función existe hasta que haya evidencia (log de CI, captura, hash de la ISO).

## Objetivos de la versión 0.1

Sistema arrancable y navegador primero (`arm64`, luego `amd64`). Streaming en beta. TV en directo, catálogo, emuladores y Store por etapas.
